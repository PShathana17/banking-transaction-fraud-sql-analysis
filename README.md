# Banking Transaction & Fraud Analytics using SQL

##  Project Overview

This project focuses on analyzing **banking transactions, customer accounts, merchants, and payment activities using SQL**. The analysis helps identify customer spending patterns, transaction trends, high-value transactions, failed transactions, and potential suspicious activity.

The project contains **150 SQL queries**, covering basic to advanced SQL concepts such as ** filtering, aggregate functions, GROUP BY, HAVING, JOINs, CASE statements, subqueries, CTEs, and window functions**.

##  Objective

The main objective is to use SQL to analyze banking data and generate meaningful insights related to:

* Customer spending
* Account activity
* Transaction patterns
* Merchant activity
* Payment methods
* High-value transactions
* Failed transactions
* Potential suspicious transaction indicators

##  Technologies & Concepts

* SQL
* JOINs
* GROUP BY & HAVING
* Aggregate Functions
* CASE
* Subqueries
* CTEs
* Window Functions
* LAG & LEAD
* RANK & ROW_NUMBER

##  Project Contents

The SQL file contains:

* Database table creation
* Sample data insertion
* 150 SQL analysis queries

The project is **self-contained**, so no separate dataset is required.

##  Key Learning

This project helped strengthen my practical SQL skills by applying SQL concepts to a **real-world banking analytics scenario**, from basic data filtering to advanced analytical queries and rule-based suspicious transaction analysis.

> **Note:** Suspicious activity in this project is identified using predefined SQL rules and does not represent confirmed fraud.
